# Create or edit an Excel workbook

Identify the decision the workbook should support, the grain of each row and the expected units. When editing a template, inspect its sheets, formulas, names and charts before choosing a tool that can preserve them. Save a copy unless replacement was requested.

Keep identifiers with leading zeros as text. Distinguish empty cells, zeros and missing observations. For rates, combine the numerators and denominators at the intended grain. Keep assumptions in labeled cells and use formulas for values the reader should be able to change. Check copied references at both ends of a range.

Reopen the saved workbook and reconcile key totals against an independent calculation. If a calculation engine is available, vary a representative input on a disposable copy and confirm the dependent result updates. Cached results can be stale. Inspect the rendered sheet when layout or charts matter. Deliver the actual workbook and identify material limits of the checks.
