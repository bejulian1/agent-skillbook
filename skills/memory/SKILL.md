# Manage a durable memory

Identify the exact fact or preference the user wants remembered, corrected or removed. Use project scope for project conventions and personal scope for preferences that carry across projects. Temporary task state belongs in the current conversation.

Use the host's documented memory mechanism when it is available and enabled. For a correction, locate the existing entry and replace it in the same scope. For removal, match the requested entry precisely. Keep credentials and unnecessary personal detail out of memory.

Confirm the resulting state using the host's acknowledgment or readback. If persistence is unavailable, tell the user what can be used during the current conversation. Avoid creating a substitute file in an unrelated location.
