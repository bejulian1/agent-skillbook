# Build or edit a PowerPoint deck

Use the audience, purpose, slide count and any supplied template to outline the presentation. Inspect existing layouts, masters, notes and assets before editing a deck. Choose an authoring tool that preserves the features the user needs.

Give each slide a question, comparison or takeaway. Keep values, units and time periods consistent in titles, charts and notes. Keep requested charts or tables editable when the format supports them. Use notes for supporting detail and source references when those would crowd the slide.

Reopen the PPTX and verify slide count, order, notes and requested native objects. Render new and affected slides when possible. Inspect text fit, chart labels, contrast, image proportions and overlap at presentation size. Deliver the actual file and identify anything the available renderer could not verify.
