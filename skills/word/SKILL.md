# Write or edit a Word document

Identify the audience, the purpose and any supplied template. For edits, inspect the document's existing heading styles, lists, sections and tables. Preserve comments, tracked changes, fields and unrelated content when selecting an editing method. Work on a copy unless the user requests replacement.

Lead with the decision, conclusion or task the reader needs. Use named paragraph and heading styles so the document stays navigable. Preserve the user's wording where an edit is local, and keep citations near the claims they support. Give tables meaningful headers and allow long rows or paragraphs to flow across pages.

Reopen the saved DOCX and inspect the edited content. When layout matters, render the affected pages and look for broken table rows, missing glyphs, orphan headings and changed page breaks. Provide the resulting file and say which visual checks were possible.
